# Agent guidance

## Agent skills

### Issue tracker

Issues and specifications use GitHub Issues in `Soulike/agent-memory-plugin`. Before ticket operations, read [issue tracker rules](docs/agents/issue-tracker.md).

### Triage labels

Use the five default canonical triage labels. Before triaging, read [the label mapping](docs/agents/triage-labels.md).

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. Before codebase exploration, design, or implementation, read [domain documentation rules](docs/agents/domain.md).
